AHE

Autonomous HumanExperiences

An AI co-worker that runs long work on a real computer, and gets better every round.

Many agents, one co-worker. They plan the work, carry out each Task on your real Mac screen, evaluate their own work, and share what they learn, so the next round starts smarter.

Watch the demo View on GitHub How it works

Run it on your Mac

  1. Clone the repository. git clone https://github.com/BaraaSoft/ahe-ai-coworker.git
    cd ahe-ai-coworker
  2. Install the packages, then run the quick start. Paste your Meta API key when it asks. pnpm install
    pnpm quickstart
  3. Open localhost:5173, and create your first strategy.

Needs macOS, Docker Desktop, Node.js 22, pnpm (no pnpm? run corepack enable), and a Meta API key. When macOS asks, allow your terminal in Accessibility and Screen Recording.
